# Прогнозирование конечных свойств композиционных материалов

Выпускная квалификационная работа по курсу «Наука о данных: профессиональный уровень (Data Science PRO)», МГТУ им. Н.Э. Баумана.

По свойствам компонентов композита (связующего и армирующего наполнителя) проект прогнозирует:

- **модуль упругости при растяжении, ГПа**;
- **прочность при растяжении, МПа**;
- рекомендует **соотношение матрица-наполнитель** (нейронная сеть).

## Структура проекта

```
├── data/                  # исходные данные (X_bp.xlsx, X_nup.xlsx)
├── notebooks/
│   └── main.ipynb         # EDA, предобработка, модели ML, нейронная сеть
├── models/                # обученные модели (joblib / keras)
├── app.py                 # Streamlit-приложение
├── train_nn.py            # скрипт обучения нейронной сети
├── environment.yml        # окружение Conda (полная сборка с нуля)
├── requirements.txt       # зависимости для pip
└── README.md
```

## Данные

Датасет со свойствами композитов: два файла объединяются по индексу (INNER). Итоговая выборка — 1022 наблюдения, 11 входных признаков и 2 целевые переменные.

## Методика

1. Разведочный анализ: распределения, диаграммы «ящик с усами», попарные графики рассеяния, анализ выбросов (правило 1,5×IQR), корреляционный анализ.
2. Предобработка: бинарное кодирование угла нашивки (0/90 → 0/1), нормализация MinMaxScaler (обучение скейлера только на обучающей выборке).
3. Модели ML: линейная регрессия, k ближайших соседей, случайный лес, градиентный бустинг; разбиение 70/30; подбор гиперпараметров — GridSearchCV с перекрёстной проверкой по 10 блокам; нормализация внутри Pipeline (исключает утечку данных). По MAE на тестовой выборке для обеих целевых переменных выбран случайный лес.
4. Нейронная сеть (Keras): полносвязная MLP (64–32 нейрона, ReLU, Dropout 0,2), Adam, функция потерь MAE, ранняя остановка; рекомендует соотношение матрица-наполнитель.

## Результаты

| Прогноз | Модель | MAE (test) | RMSE (test) |
|---|---|---|---|
| Модуль упругости при растяжении, ГПа | Случайный лес | 2,36 | 2,96 |
| Прочность при растяжении, МПа | Случайный лес | 396,9 | 496,4 |
| Соотношение матрица-наполнитель | Нейронная сеть | 0,75 | 0,94 |

## Установка и запуск

Требуется Python 3.9–3.12 (TensorFlow не поддерживает более новые версии).

**Вариант 1. Conda:**

```bash
conda env create -f environment.yml
conda activate ds
```

**Вариант 2. pip:**

```bash
pip install -r requirements.txt
```

Запуск приложения:

```bash
streamlit run app.py
```

## Обучение моделей

Полный цикл исследования и обучения — в ноутбуке `notebooks/main.ipynb`. Модели случайного леса уже обучены и лежат в `models/`. Нейронную сеть для приложения нужно обучить один раз:

```bash
python train_nn.py
```

После этого в `models/` появятся `nn_model.keras` и `scaler_nn.joblib`, и приложение будет готово к запуску.
