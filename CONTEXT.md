## О проекте

Выпускная квалификационная работа (ВКР) по курсу «Наука о данных: профессиональный уровень (Data Science PRO)», МГТУ им. Н.Э. Баумана.

**Тема:** Прогнозирование конечных свойств новых материалов (композиционных материалов). Кейс основан на реальных производственных задачах Центра НТИ «Цифровое материаловедение: новые материалы и вещества».

**Цель:** по свойствам компонентов композита (связующего и армирующего наполнителя) спрогнозировать конечные свойства материала и рекомендовать соотношение компонентов.

## Задачи по заданию (аттестационное задание ВКР)

1. EDA: гистограммы распределения каждой переменной, диаграммы «ящик с усами», попарные графики рассеяния; среднее и медиана по каждой колонке; анализ и исключение выбросов; проверка пропусков.
2. Предобработка: удаление шумов, нормализация (показать графики распределения ДО и ПОСЛЕ, указать min/max).
3. Обучить несколько ML-моделей для прогноза двух целевых переменных:
   - **Модуль упругости при растяжении, ГПа**
   - **Прочность при растяжении, МПа**
   Сплит 70/30, подбор гиперпараметров — GridSearchCV с cv=10. Метрики на train и test.
4. Нейронная сеть (Keras/TensorFlow), рекомендующая **Соотношение матрица-наполнитель**.
5. Приложение (Streamlit), выдающее прогнозы (оба: свойства + соотношение).
6. Репозиторий на GitHub с оформленным README.

## Данные

Два файла (лежат в `data/`):
- `X_bp.xlsx` — базовые свойства (1023 строки, 10 признаков + индексная колонка)
- `X_nup.xlsx` — параметры нашивки (1040 строк, 3 признака + индексная колонка)

Объединение: **по индексу, INNER join** (требование задания). Итог: 1023 строки × 13 признаков.

| Количество отвердителя, м.% | входной |

## Принятые решения (уже сделано / договорено)

- EDA выполнен, см. ноутбук. Пропусков и дубликатов нет.
- Удалена 1 ошибочная запись: `Плотность нашивки == 0` (и `Шаг нашивки == 0`) — ошибка регистрации, физически невозможна. Итоговая выборка: **1022 строки**.
- Выбросы по правилу 1.5×IQR есть (до 2% по отдельным признакам), но физически правдоподобны — **оставлены**, решение обосновано в ноутбуке.
- Мультиколлинеарности нет (все |r| < 0.5), зависимости нелинейные → нужны нелинейные модели.
- `Угол нашивки, град` — категориальный (0/90), кодируем бинарно через `replace(90 → 1)` (эквивалент one-hot для двух значений). С графиков нормализации исключаем (бинарный признак).
- Нормализация: **MinMaxScaler**.
- Под каждую целевую переменную — **отдельная модель** (свой GridSearchCV).
- В разделе предобработки (2.1) нормализация показывается пошагово с графиками до/после (нужно для записки). При обучении моделей (2.2) нормализация делается внутри `sklearn.pipeline.Pipeline` во избежание data leakage.
- Всё делается в **одном Jupyter-ноутбуке** (EDA → предобработка → модели → нейросеть). Приложение — отдельный `app.py`.
